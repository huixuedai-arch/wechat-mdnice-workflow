# 第一次使用：Skill 与插件分别安装

## 两者的关系

Skill 供助手读取，负责准备稿件、MDnice 排版、生成文章包以及解释核验结果。Chrome 插件在你登录的网页里执行导入、作者与原创设置、保存和预览。只安装 Skill 不会自动安装 Chrome 插件，也不会自动获得你的浏览器登录权限。

## 1. 安装 Skill

将本仓库链接交给支持 Skills 的助手：

> 请安装 https://github.com/huixuedai-arch/wechat-mdnice-workflow 中 skills/wechat-mdnice-workflow 这个 Skill。

或者下载仓库，把整个 `wechat-mdnice-workflow` 技能文件夹（含 SKILL.md、scripts、references、agents）复制到宿主规定的技能目录。不要只复制 SKILL.md。按宿主要求刷新技能或开启新会话。

## 2. 安装浏览器插件（一次）

1. 到仓库 Releases 下载 `wechat-mdnice-extension-1.0.0.zip`。
2. 解压到固定位置；Chrome 打开 `chrome://extensions`，开启开发者模式。
3. 点“加载已解压的扩展程序”，选择含 manifest.json 的 `wechat-mdnice-extension` 文件夹，不是 ZIP。
4. 将插件固定到工具栏。在 Chrome 登录自己的 MDnice 和微信公众号后台。

## 3. 配置作者与接收人（一次）

打开插件“本机设置”，填：公众号固定标识、文章作者、原创作者（默认同文章作者）、预览微信号，并选择是否默认声明文字原创。点击保存。

署名、微信号都是自己填写；不是 GitHub 用户名，也不会自动使用仓库开发者的身份。公众号标识是本机用于区分任务的固定名称，不是 API 密钥。无需填写 AppSecret、Cookie 或登录 token。接收微信号需符合公众号预览发送要求，建议先关注该公众号。

也可使用 Skill 的 profile.py 生成配置 JSON，再从插件导入；无需手动编辑 JavaScript。

## 4. 每篇文章操作

给助手：

> 使用这个 Skill 处理本篇文章。先经过 MDnice 实际排版，给我生成通用插件文章包。使用我已配置的作者和预览接收人，正式发表由我自己操作。

如果助手具备被允许的浏览器控制能力，可以帮你排版；没有连接或受到访问限制时，它仍可准备主稿，你在 MDnice 中完成排版。Skill 不能绕过访问限制。

获得文章包有两种方式：
- 助手基于实际导出的 MDnice HTML 用 build_package.py 生成 JSON。
- 在 MDnice 排好版并保存后，打开插件“在 MDnice 页面生成文章包”，填标题、摘要、封面图片序号，点击提取。会下载并加载本篇 JSON。

随后：
1. 在公众号后台新建空白图文编辑页。
2. 打开插件，“加载 MDnice 文章包”选择本篇 JSON（刚从 MDnice 提取的已自动加载）。
3. 核对配置摘要和稿件名，勾选授权，点“空白编辑页：导入 → 保存核对 → 发一次预览”。
4. 等待进度。收到预览后，在手机检查效果。满意后自行回公众号点发表。

换下一篇只需换文章包，不修改代码、不重装插件。仓库 examples 里的图片是示例地址，不能当真实文章运行。

## 5. 异常与升级

- `preview-sent`：页面显示发送成功；手机收到后可点“我已收到本篇预览”。
- `preview-unknown`：结果不明，先查微信，不要重复启动。
- `blocked`：已停止，下载精简诊断交给助手。报告可能含标题、署名、微信号和草稿 ID，不要直接公开贴到 GitHub。
- 已有正文不要点完整导入覆盖它。需要改作者时使用“仅更新作者和原创”；只查结果用“只读核对”。
- 升级覆盖同一安装文件夹并在扩展管理页重新加载。不要删除扩展，否则会丢失配置及防重发记录。

通用插件的多场景本地测试已通过，仍可能遇到真实平台界面变动、验证码或图片上传限制。实际反馈不明时不冒报成功。插件没有正式发表功能。
