# 使用者、素材 Agent 与插件的分工

素材 Agent：按用户风格完成稿件和图片，保存到输出根目录下的文章标题文件夹，交付完整 JSON 包。更新素材后保留 articleId、备份旧包并重新打包。跨会话需要提供 Skill 或完整包规范，不能假设另一个 Agent 记得前文。

使用者：首次配置公众号标识、文章作者、原创作者、预览微信号及输出目录；登录公众号并打开对应类型编辑页，导入包，核对后点击主按钮。`运行步骤.txt` 给使用者看，不是 Agent 的系统指令。

插件：普通文章保留真实 MDnice 排版；贴图上传原图并保留纯文本空白。保存并刷新核对后才继续预览。只提供二维码的贴图预览以 `draft-ready` 结束，通知使用者审核草稿并手工发表。微信号预览成功是 `preview-sent`，实际收件确认另记；未知发送结果不重试。

主界面为打开公众号、本机设置、导入文章包、图片信息/封面、一个执行按钮。“清空”只删加载的包及封面选择，不删配置、历史和发送记录。故障区只读采集诊断或停止任务，停止不能撤销已发送消息。只准备包、仅更新署名或只读检查不自动发送。
