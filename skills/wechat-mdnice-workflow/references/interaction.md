# 交互协议

首次配置：
- 文章作者：必填，由开发者或使用者填写。
- 原创作者：默认同上，可单独修改。
- 预览微信号：必填，由使用者填写。
- 保存目录：必填，本地绝对路径。
- 文字原创：使用者首次确认默认后启用，逐篇可覆盖。

日常输入：“这篇文章按公众号流程处理，发我预览。”
助手展示一行任务摘要（标题、作者、原创作者、接收人、MDnice 主题）；已有授权即执行，不添加第二次确认。

任务模式：
- 完整流程：MDnice → 导入 → 两个作者/原创 → 保存 → 刷新读回 → 单次预览。
- 仅更新设置：备份现有内容 → 修改两个作者/原创 → 保存核对，零次预览。
- 只读核对：读取当前草稿、作者及 checked 属性，零次写入与发送。

通用插件 1.0.0：
首次设置页保存上述配置到本机；选择每篇 article-package.json，不内置私人稿件。包包含 schemaVersion、articleId、title、summary、MDnice source URL/theme/htmlSha、html、images、coverIndex，图片数量可变。缺作者或收件人时先引导配置。包不能自行改变接收人；逐篇覆盖必须是使用者明确选择。
进度展示当前阶段、结果依据、失败字段。预览前持久化发送记录；结果不明不自动重试。重新加载插件保留记录。诊断导出选项默认不含正文、图片URL、登录令牌或完整 DOM；可能包含标题、作者、接收人和草稿 ID，不应公开上传。所有 checkbox/radio 显式记录 checked，输入字段记录 value，不能仅靠 outerHTML。

验证边界：工作流在一个真实案例完成 MDnice、导入、草稿和收件；作者与原创已由诊断和使用者反馈确认。不能据此宣称任意账号、图片数量或版本都适配。当前公开包包含通用插件、Skill、配置及文章包生成工具。通用插件已通过本地多场景模拟，尚未完成多账号真实联调。
