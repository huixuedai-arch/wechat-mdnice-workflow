没有固定风格选 A；已有写作要求或定稿选 B。每个版本都有中文和英文。

复制时会一并带上文章包格式，无需新会话记住 Skill。若换到新会话，请同时附上原稿、素材或风格参考。

请为我准备一篇微信公众号文章和配图。

写作：口语化、短段落、清晰小标题；核实关键事实，不虚构体验。每个主要部分按内容需要配图，优先使用提供的素材或可使用的官方图片。

主题或原稿：[填写主题 / 附上原稿]
保存目录：[填写本机绝对路径]

交付：在保存目录下新建以文章标题命名的文件夹。正文保存为 article.md，图片放在 images/，依次命名 01-简短描述.png、02-简短描述.jpg，保留实际图片格式。图文对应位置写在原稿中，并推荐一张封面。保留原稿、图片及可导入插件的 article-package.json，最后给出文件路径。

English

Prepare a WeChat article and its illustrations.

Writing: Use conversational language, short paragraphs and clear headings. Verify key facts and do not invent experiences. Illustrate major sections where useful, preferring supplied material or usable official images.

Topic or draft: [describe / attach]
Output directory: [absolute local path]

Deliverables: Create a folder named after the article title under the output directory. Save article.md and images/01-short-description.png, images/02-short-description.jpg, preserving actual image formats. Mark image placement in the draft and recommend a cover. Keep the editable article, images and an importable article-package.json. Provide the resulting file paths.

查看随指令附带的文章包格式
文章包格式（本条已包含规范，不依赖其他会话或预装 Skill）：
输出一个 UTF-8 JSON，只含 schemaVersion、articleId、title、summary、source、html、images、coverIndex。
schemaVersion 为 1；articleId 为 1–100 位字母、数字、横线或下划线，同篇保持稳定；title 为 1–64 字符，summary 最多 120 字符。
html 为实际 MDnice 导出的正文 HTML，保留内联样式，最多 2 MB。source 为 {"kind":"mdnice-rendered","url":"实际 https://editor.mdnice.com/ 文章 URL","theme":"实际主题","htmlSha256":"html 原始字符串 UTF-8 SHA-256 小写十六进制值"}。
images 为按正文 img 顺序排列的 1–50 项 [{"mdniceUrl":"对应 img src 的公开 HTTPS 地址"}]。可选 wechatUrl 仅可为 qpic.cn HTTPS 地址。coverIndex 为从 0 开始的有效封面图片索引。
正文只用普通排版标签，不含 script、iframe、svg、事件属性、srcset 或含 URL 的 CSS；不放作者配置、接收微信号或登录凭据。
必须使用真实 MDnice 导出，不得伪造来源或用自制 HTML 冒充。若当前无法取得导出，先交付 article.md 与图片，明确缺少真实排版 HTML，不能宣称文章包已可导入。
Package format (self-contained; no prior session or installed Skill required):
Write UTF-8 JSON with only schemaVersion, articleId, title, summary, source, html, images and coverIndex.
schemaVersion is 1; articleId is a stable 1–100 character identifier using letters, digits, hyphens or underscores; title is 1–64 characters; summary is at most 120 characters.
html is the actual MDnice body HTML export with inline styles, at most 2 MB. source is {"kind":"mdnice-rendered","url":"actual https://editor.mdnice.com/ article URL","theme":"actual theme","htmlSha256":"lowercase SHA-256 of the exact UTF-8 html string"}.
images is an ordered array of 1–50 items [{"mdniceUrl":"public HTTPS URL matching the corresponding body img src"}]. Optional wechatUrl must use a qpic.cn HTTPS address. coverIndex is a valid zero-based image index.
Use ordinary formatting tags, no scripts, iframes, SVG, event attributes, srcset or URL-bearing CSS. Exclude author configuration, recipients and credentials.
Use a real MDnice export. Never fabricate the source or label custom HTML as a MDnice export. If no actual export is available, deliver article.md and images and clearly identify the missing formatted HTML; do not claim the package is importable.
